# Иконки платформ

42 локальных бренда с фирменными цветами по умолчанию. Десять новых файлов владельца (YouTube SVG, TikTok, Threads, Snapchat, WhatsApp, VK, CapCut, Дзен, Mastercard и Tesla) сохранены без изменений. Источники и SHA-256 всех используемых файлов: `public/icons/platforms/brand-assets.json`. Большинство остальных знаков получено с официальных сайтов; Figma, Fansly и Ozon — из явно указанных зеркал фирменной графики на Wikimedia Commons. Названия и знаки принадлежат владельцам брендов. Старые Simple Icons сохранены с лицензией, но компонент больше не рисует их масками.

Выбор одинаковый во всех представлениях: локальный бренд → сохранённый на нашем домене PNG → видимый глобус. Закрытая страница владельца получает иконки как редактор. Большая карточка использует тот же снимок.

Основной сборщик — стандартный PHP curl на Beget, запасной — Supabase Edge в EU. Бюджет 9.8 секунды включает DNS, сеть и конвертацию. Curl пиннит проверенные публичные адреса, проверяет TLS/hostname и каждый редирект, использует HTTP/2 при наличии и ограниченное распакованное тело. IPv4/IPv6 и кандидаты идут параллельно с ранним выходом; декодер ICO/SVG ограничен временем, памятью и числом пикселей. В EU остаётся отдельный транспорт с проверенным IP и исходным TLS hostname. Непубличные DNS-ответы и редиректы отклоняются; SVG с кодом, внешними ссылками или сущностями не декодируется.

PNG хранятся постоянно в закрытом `.private-assets/link-icons`, обновляются через 6 часов и сохраняются при неудаче. Браузер перепроверяет PNG через 5 минут. Адреса `/i/v2/...` обходят прежний HTML-кэш; старые корректные адреса перенаправляются 301. Служебные ошибки не содержат HTML и не кэшируются. HTML приложения отдаётся `no-store` без ETag/Last-Modified.

Проверки: PHP, транспорт/DNS, настоящий Apache, desktop/mobile Chromium и официальный Яндекс Браузер. Сценарии и ограничения приёмки: `docs/issue-70-acceptance.md`. При выпуске согласованно обновить favicon Edge Function и PHP/client.
