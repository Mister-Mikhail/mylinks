# Иконки платформ

30 локальных знаков: прежние 11 сохранены; 19 SVG добавлены из npm `simple-icons@15.0.0` (CC0, копия LICENSE рядом с файлами). Названия и знаки остаются товарными знаками владельцев. SVG используют маску и цвет текста для контраста без подложки. Произвольные сайты получают favicon с fallback.

Прокси принимает только HTTPS стандартного порта, проверяет весь результат DNS, подключается к проверенному IP с исходным Host/SNI и проверкой сертификата. Каждый redirect проверяется заново (до трёх переходов); загрузка ограничена размером и временем. Непубличные IP и переходы на них отклоняются. Корневой домен определяется Public Suffix List через закреплённый tldts 7.0.22, включая частные суффиксы. Ограничение повторных промахов работает в пределах экземпляра; распределённая защита от объёмной нагрузки — отдельный инфраструктурный уровень.

Память прокси и серверные PNG обновляются через 6 часов; браузер PNG перепроверяет через 6 часов. Недоступность источника сохраняет последний пригодный PNG. Адрес, ID ссылки и её статистика не меняются.

Проверки: `node --experimental-strip-types --test supabase/functions/favicon/safe-fetch.test.ts`, Deno check, PHP тесты кеша и браузерная матрица 30 платформ. При выпуске обновить Edge Function favicon и PHP link-icon.php совместно.
