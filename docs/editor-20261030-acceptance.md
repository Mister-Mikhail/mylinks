# Редактор после PR #77 и аватар «Во всю ширину»

Исходная версия: `b14aaca32b8bd831c3102869b0416b67e06114d7` (PR #77). Ветка: `fix/editor-polish-full-avatar`. Пакет A–C от 30.10.2026. Слияние и публикация владельцем **не разрешены**.

## Изменения

- 18+: одна строка с подписью слева, стандартным переключателем справа и принудительным состоянием для известных площадок.
- Нижний запас прокрутки учитывает кнопку превью, навигацию и safe-area. Проверяется реальный элемент в центре последней стрелки.
- Настройки выбранной карточки раскрываются под строкой, включая ссылки в группах. Повторный клик сворачивает, открыта одна карточка; старый отдельный блок и прокрутка удалены.
- Меню закрывается снаружи, по Esc и при смене раздела. Удаление аккаунта перенесено в последний красный пункт с разделителем; содержание диалога сохранено.
- Мобильная шапка 56 px: знак логотипа, сокращаемое название, иконки открытия/отправки, сохранение с текстом и меню.
- Общие токены геометрии: карточки 20/16 px; промежутки 16/12/6 px; поля 44 px, кнопки 40/36 px; поле 14/16 px; подписи 12 px, подсказки 11 px, заголовки 15 px.
- Поле мастер-ссылки, цвет 44 + min96 + 44, порядок настройки шрифтов, кнопки изображений, ползунки, подписи и строки приведены к общей сетке. Ленты сохраняют жесты и затухание, системная полоса скрыта.
- `square`: нулевое скругление во всех поверхностях и кадрировании; обводка сохранена.
- `full`: отдельная строка аватара по ширине профиля, 4:5, без рамки/скруглений; размер скрыт, прежнее значение хранится для возврата к кругу/квадрату. Общие компоненты работают в публичной странице, обоих превью, онбординге и админском редакторе.
- Сервер кодирует фото/видео 560×700 и 1000×1250; сохраняет выбор по ширине/DPR, MP4 H.264 и постер. Социальная картинка принимает 4:5, версия её кэша обновлена.
- Миграция расширяет ограничение и заменяет текущие RPC без потери логики/прав; edge `admin-profile` принимает `full`. JSON-экспорт сохраняет новое значение. Отдельного UI импорта в MVP нет; действующие пути переноса/сохранения принимают `full`.
- Удалены оба временных условия `feature/editor-layout-after-glass` из CI. Новые сценарии включены в реальный Yandex suite.
