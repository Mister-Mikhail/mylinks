# Экспорт профиля, версия 1

Владелец скачивает JSON в разделе «Экспорт данных». Источник — сохранённое состояние БД. Экспорт ничего не записывает в профиль. Сначала завершите сохранение в редакторе.

Обязательные поля: `schema_version: 1`, `exported_at` (ISO UTC), `canonical_url` (https://mylinks.bar/{handle}). Отсутствующий раздел означает, что пользователь его не выбрал. Пустой массив означает, что в выбранном разделе нет записей.

- `profile`: handle, display_name, bio, is_published, created_at, updated_at. Нет email учётной записи, пароля, токенов, служебных метаданных.
- `links`: массив в порядке position; id исходной ссылки, label, url, icon_key, is_visible, is_sensitive, label_font и label_font_size.
- `contacts`: kind, label, value, координаты адреса, типографика, position, is_visible. Контакты включаются по выбору владельца, скрытые значения — по отдельной отметке.
- `appearance`: тема, собственные цвета и градиент фона; пресет, радиус, рамка, отступы и плотность карточек; форма/размер/кроп аватара; шрифты, размеры и цвета верхних строк и общих ссылок; видимость и размер QR. Индивидуальные `card_preset_override`, `card_radius_override`, `card_style` и цвет подписи входят в каждую запись `links`. Значение `null` сохраняет наследование.
- `assets`: kind (avatar/avatar_poster), bucket, path. Файлы не встроены. При явном выборе добавляются download_url и expires_at, срок ссылки — 300 секунд. Скачайте файлы до истечения срока; храните экспорт с личными данными у себя.
- `statistics`: сводка за всё время, дневные счётчики и счётчики ссылок. Нет индивидуальных событий, IP-адресов и идентификаторов посетителей.

Импортирующая система должна проверить schema_version, валидировать значения, создать новые IDs и сохранить соответствие IDs ссылок для счётчиков. Storage paths относятся к исходному аккаунту: файлы нужно загрузить в хранилище нового владельца, а пути заменить. Исходные timestamps не дают права подменять серверные timestamps. Сам импорт пока не реализован.

Клиент ограничивает экспорт 10 МБ, 1000 ссылок и 1000 контактов за раз, повторное начало — раз в 10 секунд. Авторизация выполняется сервером Supabase и существующими RLS-политиками владельца; клиент дополнительно проверяет соответствие IDs. Никаких внешних сервисов экспорта или QR-кодов не используется.

QR-код всегда содержит canonical URL сохранённого user name, PNG 1024/2048 px или SVG. После смены user name старые печатные QR-коды потребуется заменить. Приватная страница не публикуется при скачивании кода.

Обновления пакета 19.10.2026: оформление включает `background_image_path`, `background_overlay`, `link_layout` (JSON v1 с заголовками, разделителями и группами ссылок); записи links — `presentation`, `image_path`, `image_alt`, `image_position_x/y`. Манифест assets перечисляет фон и изображения карточек из частного bucket `profile-assets`. Ссылки на скачивание по-прежнему выдаются только по явному выбору на 300 секунд. ID в структуре групп требуется переназначить через ту же карту ID, что и ссылки, при будущем импорте.
