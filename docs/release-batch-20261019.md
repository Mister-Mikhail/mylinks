# Пакет 19.10.2026 — пять пунктов ТЗ и исправления редактора

Порядок: B13 экспорт → B07 иконки → исправления цветов/сетки/входа в шаблоны → B02 фоны → B08 featured-карточки → B09 группы. У каждого этапа отдельная ветка и PR; проверка до открытия PR: lint/build, PHP, PostgreSQL, desktop/mobile e2e, Deno для серверных функций.

- Экспорт: новые параметры оформления, наследование, QR; последующие этапы добавляют фоновые файлы, изображения карточек и структуру групп в тот же версионированный формат.
- Иконки: 30 локальных платформ, PSL на сервере, проверка DNS и перенаправлений, соединение с проверенным IP при сохранении Host/SNI; кеш PNG обновляется через 6 часов. См. ICONS.md.
- Цвета: единый HEX с вводом RGB и копированием, собственная палитра с закрытием снаружи/Escape. Исправлена сетка раздела «Ссылки». Галерея шаблонов доступна из «Ссылок» через явную кнопку.
- Изображения: JPG/PNG/WebP до 10 МиБ/30 Мп, серверное преобразование в WebP до 1600 px/1,5 МБ, удаление метаданных. Bucket profile-assets закрыт; анонимное чтение разрешено только для файлов, на которые ссылается видимый опубликованный профиль/featured-ссылка. Загрузка не публикует черновик. Использованные раньше файлы сохраняются для возврата; неиспользованные частные загрузки требуют периодической уборки, чтобы не накапливать расход Storage.
- Featured: прежний link_id и события сохранены, положение изображения задаётся по двум осям, обычный режим сохраняет файл; скрытые ссылки не дают публичный доступ к файлу. В публичном рендере 18+ использует предупреждение и placeholder вместо картинки.
- Группы: заголовки, разделители, порядок блоков, перенос ссылок между группами, разгруппировка без удаления ссылок, пустые группы. Структура JSON v1 содержит только ссылки на принадлежащие профилю IDs; сервер отклоняет чужие/повторные ссылки и произвольные ключи. Удаление ссылок очищает структуру; старые профили с null используют прежний рендер.

## Выпуск

Production этим пакетом пока не изменён. Перед выпуском применить три новые миграции по порядку, обновить favicon и admin-profile, затем публиковать PHP/React. Миграции проверяются повторным применением на одноразовом PostgreSQL; существующие ID, URL и события не переписываются. Перед включением новых функций зафиксировать резервную копию и количество профилей/ссылок/событий. Откат — предыдущий код; новые поля и частные файлы не удалять.

Требования к будущему полноценному редизайну шаблонов записаны отдельно в template-composition-next.md. Этот пакет добавляет функциональную основу; текущие девять цветовых наборов не считаются принятым редизайном композиции.
