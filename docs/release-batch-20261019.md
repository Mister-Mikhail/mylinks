## Выпуск

Владелец одобрил публикацию 20.10.2026 (Москва). Три миграции применены по порядку, admin-profile обновлён до версии 7; favicon использует нативное TLS-соединение к проверенному IP. PHP/React публикуются автоматически из main; итоговая проверка развёртывания фиксируется в PR выпуска. Миграции проверяются повторным применением на одноразовом PostgreSQL; существующие ID, URL и события не переписываются. До миграций сохранены определения изменяемых функций для отката и контрольные суммы профилей/ссылок: 10 профилей, 30 ссылок, 8 контактов, 60 событий. После миграций контрольные суммы совпали; RLS включён, bucket profile-assets закрыт, новые поля сохранили прежнее отображение. Откат — предыдущий код; новые поля и частные файлы не удалять.

Требования к будущему полноценному редизайну шаблонов записаны отдельно в template-composition-next.md. Этот пакет добавляет функциональную основу; текущие девять цветовых наборов не считаются принятым редизайном композиции.

При живой проверке обнаружена несовместимость node:https с передачей SNI в Edge Runtime: запросы к IP отклонялись проверкой имени сертификата. Исправлено через Deno.connect к проверенному IP и Deno.startTls с исходным hostname; проверка сертификата не отключается. 38 тестов защиты/HTTP/TLS и Deno check пройдены; реальные ответы mylinks.bar, Wikipedia и Google — 200. Временные диагностические маршруты удалены.
